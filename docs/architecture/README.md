# Architecture

This directory contains durable architecture contracts and architecture guidance for Antena Hotel Check.

## Current architecture documents

- [EVALUATION-ARCHITECTURE — Evaluation Architecture Contract](./EVALUATION-ARCHITECTURE.md)
- [architecture-concerns — Architecture Decision Areas](./architecture-concerns.md)

## Rules

- Architecture contracts must remain consistent with approved product specifications.
- Do not introduce framework, cloud, database, browser, queue, hosting, rendering, or AI-provider choices unless explicitly approved through the project's decision process.
- Material architecture choices belong in `docs/decisions/` with alternatives and consequences.
- Implementation sessions must stay within the architecture boundaries and exact requirement scope assigned to them.
